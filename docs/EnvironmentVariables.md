# Environment Variables

Below is a list of all environment variables defined for HostManagement.

| Variable                                                   | Description                                                                                                                    | Default value                                        | Current value in the Linux image*                               | Required                                     |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- | --------------------------------------------------------------- | -------------------------------------------- |
| `HOSTMANAGEMENT__BYPASS_VALIDATION_CHECKS` (script only)   | If set, certain validations are skipped (e.g. during the OS startup phase when not all required information is available yet). | `""`                                                 | `true`                                                          | Yes during early OS startup; No in operation |
| `HOSTMANAGEMENT__CONFIGURABLE_SERVICES`                    | List of Linux services that can be configured by HostManagement                                                                | `""`                                                 | `ssh.service,remoteconnect.service`                             | No                                           |
| `HOSTMANAGEMENT__DEFAULT_SYSTEM_CONFIGURATION_DIRECTORY`   | Directory in which `DefaultSystemConfiguration.json` is located                                                                | `/tmp` (no persistence possible)                     | `/etc/hostmanagement`                                           | No (Yes for persistence)                     |
| `HOSTMANAGEMENT__IGNORED_NETWORK_INTERFACES` (script only) | List of network interfaces ignored by HostManagement                                                                           | fixed to `lo,docker` in `get_network_interfaces.sh`  | `lo,ifm-mrc`                                                    | No                                           |
| `HOSTMANAGEMENT__PIPE__CHMOD`                              | Permissions of the named pipe (numeric notation)                                                                               | `664`                                                | `664`                                                           | No                                           |
| `HOSTMANAGEMENT__PIPE__GROUP`                              | Group of the named pipe                                                                                                        | `vicione-suite` (`root` if the group does not exist) | `vicione-suite`                                                 | No                                           |
| `HOSTMANAGEMENT__PIPE__USER`                               | User/owner of the named pipe                                                                                                   | `vicione-suite` (`root` if the user does not exist)  | `vicione-suite`                                                 | No                                           |
| `HOSTMANAGEMENT__PUBLIC_KEYS__[0...x]`                     | List of known public keys used to verify installation files etc.                                                               | `""`                                                 | `%%KEY%%`                                                       | No (Yes for updating the ViciOne Suite)      |
| `HOSTMANAGEMENT__RESOURCE_DEPLOY_DIRECTORY`                | Directory to which all resources (scripts) are deployed when the service starts                                                | `/tmp/HostManagement_Resources`                      | `/var/lib/hostmanagement`                                       | No                                           |
| `HOSTMANAGEMENT__SUITE_DOWNLOAD_DIRECTORY`                 | Directory to which the ViciOne Suite Debian package is downloaded during installation/update                                   | `/tmp`                                               | not set                                                         | No                                           |
| `HOSTMANAGEMENT__SUITE_REPOSITORY__ENDPOINT`               | ViciOne Suite repository endpoint (URL)                                                                                        | `""`                                                 | `https://system.update.ifm/artifactory/vicione-suite/suites`    | Yes                                          |
| `HOSTMANAGEMENT__SUITE_REPOSITORY__PACKAGE_API`            | API to be used for downloading the packages                                                                                    | `""`                                                 | `jfrog`                                                         | Yes                                          |
| `HOSTMANAGEMENT__SUITE_REPOSITORY__PASSWORD`               | ViciOne Suite repository password                                                                                              | `""`                                                 | `%%PASS%%`                                                      | Yes                                          |
| `HOSTMANAGEMENT__SUITE_REPOSITORY__USERNAME`               | ViciOne Suite repository username                                                                                              | `""`                                                 | `%%USER%%`                                                      | Yes                                          |
| `HOSTMANAGEMENT__SYSTEM_CONFIGURATION_DIRECTORY`           | Directory in which `SystemConfiguration.json` is located                                                                       | `/tmp` (no persistence possible)                     | `/mnt/persistent/hostmanagement`                                | No (Yes for persistence)                     |
| `HOSTMANAGEMENT__TARGET_ENVIRONMENT`                       | Target environment/platform, e.g. `EdgeS` or `"Standard" Debian`                                                               | `unknown`                                            | depends on target environment, e.g. `edges-vicione` or `debian` | Yes                                          |
| `HOSTMANAGEMENT__UPDATE_DIRECTORY` (script only)           | Directory in which `.swu` files must be placed for updates                                                                     | not set                                              | `/mnt/update`                                                   | Yes                                          |
| `LOGGING__LOGLEVEL__DEFAULT`                               | Application `LogLevel`                                                                                                         | `Warning`                                            | not set                                                         | No                                           |

* The values in the Linux image differ between releases and products and may change at any time. The values shown are examples for better understanding only.
* script only: On startup, HostManagement checks whether all environment variables are set. If this is not the case, an error message is logged. Variables marked as "script only" are exceptions, as they are currently used directly in shell scripts and are not known to HostManagement itself.
